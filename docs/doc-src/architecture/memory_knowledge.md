# 记忆与知识架构

本文定义 AI 记忆入口的重构设计，2026-09-15 首次制定，实施状态和验证见
[专项计划](../../TODO/memory_knowledge_refinement/index.md)。计划项不能作为当前已实现能力。

## 研究与设计依据

本轮实际读取的第一手公开资料：

- [OpenAI Memories](https://learn.chatgpt.com/docs/customization/memories)：本地记忆与 ChatGPT Web 分离；
  使用记忆和贡献记忆分别控制；后台处理符合条件的历史会话；摘要、长期条目与原始证据分层；
  记忆不能成为必须执行规则的唯一来源。
- [Claude Code memory](https://code.claude.com/docs/en/memory)：用户规则与自动笔记分离；
  精简 MEMORY.md 索引与按需读取的主题文件；记忆可检查、修改、删除，记录更新时间。

以上证明的是公开行为，不能据此声称知道私有检索模型、完整内部算法或行业最优实现。
Kiyori 为 Android 应用，已有结构化库及图关系；照搬桌面 Markdown 目录会形成第二事实源，
因此采用其分层读取、范围、来源和可纠正原则，保留现有 ObjectBox、角色绑定与 HNSW 实现基础。

## 产品边界

| 对象 | 保存什么 | 如何使用 | 如何维护 |
| --- | --- | --- | --- |
| 用户档案 | 用户明确维护的长期资料 | 现有 user.md 注入路径 | 仍由 UserProfileDocumentRepository 持有 |
| 记忆 | 稳定偏好、事实、决策、经验及有时间背景的事件 | 查询候选摘要，再读取必要条目 | 标题、正文、主题、标签、来源、时间；编辑、归档、恢复、删除 |
| 知识 | 用户提供的长文档、参考资料及摘录 | 找资料，再按分块读取和引用 | 文档元数据、内容块与原始来源；导入、检索、编辑、删除 |
| 关系 | 条目间用户或 Agent 明确建立的联系 | 受范围限制的检索扩展、可选图谱 | 关系类型、权重、说明；不是无来源的“知识真相” |

记忆空间继续是角色隔离边界；记忆/知识是空间内的内容类型，不复制数据库。
文件夹表达领域或项目，标签表达交叉主题，不强制给用户创建一棵预设空目录。
分类使用少量稳定语义：偏好、事实、决策、经验、事件、其他；旧内容保留原分类，不让模型擅自改写。
归档保留内容但从日常与 Agent 检索排除，恢复重新可查；删除明确确认，不自动遗忘或合并。

## Agent 读写闭环

1. 判断本次是否需要历史信息；简单自足任务无需检索。
2. 使用既有 `query_memory`，限定当前角色的空间、内容类型、文件夹和时间。
3. 返回有界候选信息与稳定 UUID；同标题不能作为唯一身份。需要完整内容时再读取。
4. 引用来源和更新时间；历史事实可过期，重要且易变的事实重新验证。相似度不是事实置信度。
5. 保存可复用、独立可理解的内容，写清条件、结论和来源，不保存整段工具日志或凭据。
6. 明确更新已有条目时用稳定标识；冲突先展示或解释，不凭标题相同删除或合并。
7. 自动提取继续走原调度器和模型功能配置；手动操作、自动抽取和导入资料区分来源。

记忆正文和文档均是数据，不提升为系统规则或外部副作用授权。检索、阅读与写入仍经现有工具权限链。

## 存储、兼容与索引

MemoryRepository 继续持有 ObjectBox 事实及索引管理，UI 只消费查询结果。
新增字符串元数据在 ObjectBox 实体构造器中接受 null：native cursor 读取旧记录时不会调用
Kotlin 默认参数。`MemoryLibraryPolicy` 将缺失主题解释为 `other`，按旧 `isDocumentNode`
投影知识类型，将缺失向量身份解释为待重建；UUID、ID、属性 UID、空间和关系不变。
备份增加可选字段并接受旧格式，文档与区块不能在导入导出时退化为普通短记忆。

向量身份必须包含规范化端点、模型及输入内容指纹；API Key 不进入身份或日志。
维度仅是必要条件，同维度不同模型也不能比较。旧来源未知向量显示待重建，不能冒充有效。
内容更新使旧向量失效；重要性、文件夹等非嵌入输入变化不触发无用网络请求。
云嵌入关闭时本地文本仍可管理和关键词检索；显式语义路径失败必须可见。
索引是派生缓存，写入采用临时文件和原子替换；损坏必须报告，重建是明确操作。
同一空间的索引变更串行，避免不同 Repository 实例互相覆盖；长网络调用不能持有数据库事务。
普通新增、编辑和文档保存先完成所需嵌入，再在空间索引锁内使缓存失效并提交数据库。
索引失效失败发生在事实提交之前，避免保存失败提示诱发重复创建；新建标签随主体事务保存。
索引统计仅在设置页按需执行，每批读取 128 项并复用配置指纹；统计错误有独立可重试状态，
不让后台未处理异常终止进程。统计是管理视图，跨批并发变更后可刷新，不作为事务一致备份。

知识分块有确定字符上限和有限重叠，优先段落/句边界，避免超长单段发送。
导入有文件/文本规模限制，明确拒绝超限，不静默截断。取消、失败和重复点击保留可判断的状态。
检索复用现有多路排序，增加正文召回与类型/归档的范围过滤；图扩展不能带回范围外或已归档内容。
不以“加一个向量数据库”代替检索质量；通过固定样例验证正文、中文、精确标识、同名、无命中及范围隔离。

## UI 与交互

首页采用 MaterialTheme 既有颜色、字体和形状。列表默认，不在普通浏览时运行全量力导向图。
上部显示当前空间与“记忆 / 知识”；搜索保留当前范围，支持清空、提交、加载与错误重试。
整理区提供主题、文件夹、标签、排序和归档入口。卡片展示标题、短摘要、来源、更新时间和索引状态。
空库解释保存什么并提供直接操作；无搜索结果保留筛选条件并允许重置。

只保留一个主要新建/导入入口；图谱关联与框选操作仅在图谱模式出现。
详情提供完整正文、标签、来源、时间、编辑、归档/恢复、确认删除；文档详情仍支持块阅读。
编辑保留所有填写字段，校验标题和正文，保存失败保留草稿，忙碌时禁止重复提交。
新建默认继承当前文件夹；普通条目编辑的未保存修改离开前确认。筛选可一键重置，
标签选项来自当前范围而不是已经被主题/标签过滤后的结果；卡片摘要截取到 400 字符后布局。
保存忙碌状态独立于列表查询，查询刷新不能解除保存锁。搜索模拟继承类型与归档范围。
空间/目录选择采用有遮罩的模态层，Back 先关闭当前层；后台页面不抢占返回。
索引设置明确本地数据与云端文本处理、模型身份、覆盖和失败，高级权重与检索模拟保留在高级入口。

## 验证矩阵

| 风险 | 自动证据 | 现场边界 |
| --- | --- | --- |
| 旧数据和备份 | 默认分类、旧格式解码、文档/元数据往返 | 已有设备库恢复 |
| 错误向量 | 同维不同模型拒绝、非法向量拒绝、内容失效 | 实际供应商响应 |
| 文档规模 | 分块上限、覆盖、确定性和空文档 | PDF/DOCX 真实提取质量 |
| 检索准确性 | 正文匹配、类型归档、同名稳定标识 | 语义质量和大库时延 |
| 并发与交互 | 代际与单一查询发布、失败草稿保留、编译 | 快速切换、旋转、Back、TalkBack |
| 交付 | 专项回归、文档检查、Debug APK、精确 Git 树 | 安装、设备、Release、远端 CI |

性能不声称零延迟或无限规模；图谱限制展示规模，检索和持久化在后台执行，列表惰性渲染。
后续引入本地嵌入模型、重排序服务或新数据库必须有基准收益与明确配置授权，不作为本轮隐式依赖。
