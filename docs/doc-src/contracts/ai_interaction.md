# AI 对话交互契约

本文定义 AI 主对话、消息操作、历史选择与悬浮输入的交互边界。模型提交与工具执行见 [AI 请求与执行](ai_execution.md)，导航归属见 [应用壳](product_shell.md)，阶段验证见 [体验专项](../../TODO/ai_chat_experience_refinement/index.md)。构建与单元测试不替代 IME、触控、语音和实际截图验收。

## 输入与草稿

- Agent 与 Classic 共用实体 Enter 策略：启用 Enter 发送时，仅第一次按下触发提交；重复事件和抬起不再次提交。Shift+Enter、未启用发送以及正在组合输入的字符交回编辑器；小键盘 Enter 与普通 Enter 使用同一策略。
- 输入插件的提交处理可能挂起。主对话在该提交处理中拒绝重复派发，返回后核对 chat、正文、附件与回复目标；已变化时保留当前内容并明确提示。取消必须继续传播，不可被解释为允许发送。
- 提交插件异常阻断当前发送，并显示不含插件原始错误内容的反馈。排队项暂时移出后，准备失败或取消必须归还原队列，按稳定 ID 保持顺序；已删除聊天不重建队列。明确被插件消费或开始交给发送流程后不恢复该项，后续异常提示核对请求状态，禁止把未知提交当作未执行。
- 全屏编辑器在打开后获得焦点，本地编辑值可随 Android 保存状态恢复；关闭或确认将编辑值交回现有草稿 owner。标题与按钮分配独立宽度，长标题不能挤出操作。
- 新建分组以原聊天仓储创建空聊天，服务持有操作并等待创建提交；UI固定打开时的角色/群组绑定，执行中禁重复创建。创建失败保留名称；创建完成后的选择失败明确提示已创建，不重复创建。设置当前聊天以DataStore事务比较原选择，其他入口已切换时保留新选择并提示。消息加载继续由原选择collector持有，创建成功不等于加载/开场白同步已验收。
- 原生历史分组操作显式携带全部、角色卡、角色群组或未绑定范围；默认角色的当前分类可包含未绑定聊天，但排除群组绑定。显示筛选与操作共用绑定匹配规则，群组ID优先于遗留角色名。改名与删除等待服务持有的结果，失败保留输入/确认；删除前固定成员与锁定快照，停止相关执行、迁移当前聊天后在Room事务内再次比较，成员或锁定变化即拒绝。锁定聊天仅移到未分组，数据库提交后的清理失败单独报告部分完成。Web兼容接口原有null角色表示全部的语义不变。
- 历史删除确认等待服务持有的持久化结果，执行期间禁重复删除和关闭，不提前隐藏条目。删除前失败保留确认；实体已删除但载荷或偏好清理失败时明确报告部分完成并撤销对应待发队列，不允许在该确认中重复删除。清除当前聊天偏好必须在DataStore写入事务内比较目标ID，不能清掉更新后的选择。
- 附件移除动作的无障碍名称包含文件名；排队消息使用稳定队列 ID，动作具有完整点击区域。

## 消息选择、确认与分享

- 消息正文编辑按聊天、消息时间戳和回答 variant 隔离组合，保存复用现有审计修订入口并校验打开时原文；成功后才关闭，失败保持草稿和重试入口，保存期间禁用重复保存与重发。关闭有未保存内容时需要确认。
- 可视化编辑与纯文本编辑使用同一正文，输入回调同步更新；XML 标签前后及之间的纯空白仍属于原文，解析和重组不得删除。只打开编辑器或切换模式不会写出规范化正文；长按钮允许换行，图标动作保留48dp点击区。

- 列表索引只表示当前显示窗口的位置。多选状态持有消息时间戳，每次从当前窗口投影索引；分页、前方插入或删除不能改变选中身份。已离开显示窗口的目标不被隐式替换为新行。
- 删除确认固定 chat 与所确认消息时间戳，异步删除委托不得在执行时重新读取索引来决定目标。编辑和工作区回滚确认同样绑定消息身份。
- 分享面板使用打开时的消息快照；参数改变时取消旧生成，关闭面板时取消当前生成。旧任务取消后不得发布结果，也不按生成失败展示取消错误；新图就绪前不保留可分享的旧图。
- 工作区回滚在操作前固定 chat 与消息身份，从持久历史确定真实前驱；分页窗口首条不能被当成全历史首条。预览加载中或失败时禁止确认，取消保持取消语义。
- 历史截断先停止目标对话执行，再在同一历史变更区间完成工作区恢复。恢复失败不删除历史；恢复 I/O 中切换页面时，已固定目标的历史操作仍只完成旧对话，不改新对话的显示窗口、草稿或发送状态。

## 历史搜索

- 选择操作在原服务串行保存已固定的原聊天统计，再校验目标存在与持久化选择原值；历史入口等待选择结果，失败保留入口。全局选择的观察与写入均来自原 DataStore；读取失败保留最后有效 ID，不能伪造空选择。原仓储共享观察区分首次加载、有效值与安全错误，用户显式重载只消费该次失败，不静默重新订阅。
- 主窗口实际选择通过原 runtime 同步到浮窗；新选择取消旧读取，旧来源请求在提交前核对当前资格。主窗口空选择不强制替换浮窗的独立本地选择，聊天删除仍由原存在性观察清理。浮窗返回主应用等待选择写入结果，失败保留窗口，等待时禁止重复返回；持久化成功不等于消息加载或角色偏好同步完成。角色绑定查找及双偏好写入之间逐次核对聊天资格；失去资格时停止后续写入并保留已发生的单项偏好事实。

- 原生历史拖拽、上移和下移提交单个聊天的位置/绑定快照及相邻可见锚点；置顶与非置顶使用各自的排序桶。仓储在同一Room事务中读取完整当前列表，校验移动项及锚点未改变，只移动该项并同步提交分组和角色绑定。搜索或折叠隐藏的条目必须保留，其他聊天的相对顺序和最新标题、统计、工作区等字段不能被旧UI快照覆盖。服务持有提交，UI等待结果并显示错误；列表仍由原Room Flow投影，排序不伪造最近编辑时间。

- 当前聊天显示窗口仍由原服务的聊天 ID、消息 Flow 与 `CurrentChatWindowController` 共同发布。选择、刷新、前后分页、最新窗口和定位携带同一控制器借出的聊天/代次及消息边界快照；切换、取消或实时更新后，旧读取不能发布消息、边界、错误或结束新请求的加载状态。全局选择使用 `collectLatest`，空选择清除旧窗口；数据库读取失败不能当作聊天不存在而清除选择。
- 运行时消息更新撤销在途读取资格并保留新内容，包括沿用同一 stream 对象的更新。读取失败或内容变化显示安全提示；重试原子消费该次错误并固定新请求，不使用迟到 UI 回调重试其他聊天。重试和关闭仅作用于对应错误；自动回到最新窗口在失败提示存在时停止请求。开场白先持久化再按窗口快照发布，未完成首次读取时不把空投影当作空历史。

- 历史列表的标题与角色/群组编辑使用打开时的聊天快照，保存期间禁止重复操作，实际持久化成功后关闭。标题与互斥绑定在原聊天仓储锁内、同一 Room 事务中提交；只合并用户修改的字段，保留其他入口修改的无关字段，同字段冲突或聊天已删除时拒绝保存并保留输入。列表投影继续来自原 Room Flow，迟到保存结果不另行覆盖列表。

- 标题与分组即时匹配；至少两个字符时，防抖后补充正文匹配，最终结果取并集。标题已有匹配不阻止其他聊天通过正文进入结果。
- 查询改变时撤销旧查询的匹配、加载与错误投影；协程取消保持取消语义。数据库失败正常传递到界面，明确显示正文搜索失败与当前结果范围，不能伪装为没有匹配。
- 搜索过程中仍可清空关键词。空历史与无匹配使用不同提示；空列表不保留无内容的分组占位。搜索正文不进入错误日志。

## 悬浮输入与键盘生命周期

- 收起扩展输入区不清空草稿；发送与用户编辑继续使用现有 FloatContext 与服务委托。
- 小窗输入采用文字在上、动作在下的结构，在窄窗口中给正文完整可用宽度。键盘发送在生成中不代替显式停止按钮取消回答。
- 主界面、小窗及扩展输入框分别持有独立 IME 声明身份；AIForegroundService 汇总所有仍可见的声明来暂停唤醒监听。退出组合只释放本组件身份，旧输入框的迟到释放不能覆盖新输入框或主窗口。
- 焦点请求绑定输入框组合生命周期，退出后自动取消。麦克风和语音播放的实际资源仍归已有语音服务持有。

## 语音消息与资源交接

- 录音操作按调用身份串行交接；新页面先启动、旧页面后清理时，只能释放旧请求。组合退出即撤销结果资格，释放不依赖已取消的 UI scope；取消等待最终识别不能继续提交迟到结果。
- 长按说话的指针协程取消时撤销本次捕获；短按移动超过触摸阈值不误开键盘。最终识别补正待发送正文，编辑面板的 IME Send 与发送按钮走同一动作。
- TTS 播放与停止在共享串行区间内核对页面身份；浮窗服务不另起无归属的共享语音清理。窗口销毁显式结束 Compose 组合。
- 手工与关键词附件采集返回实际结果。准备中禁止重复发送；失败保留正文，自动语音正文进入编辑面板供复核。准备结束后核对窗口、chat 与当前草稿；只有有效提交才清除对应输入。
