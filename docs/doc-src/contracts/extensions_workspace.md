# 扩展、工具与工作区契约

本页覆盖 registry 生命周期、宿主接口与工作区边界。开发 API 见 [脚本指南](../../SCRIPT_DEV_GUIDE.md)、[ToolPkg 格式](../../TOOLPKG_FORMAT_GUIDE.md) 和 [宿主类型入口](../package-dev/index.md)。

## 插件解析与输入同步

- ToolPkg 预览和实际加载使用相同 manifest 优先级：根 hjson、根 json、嵌套 hjson、嵌套 json，
  同类先选较浅目录，再以固定字符顺序确定。既有产物策略排除的备份/依赖目录不参与 manifest
  选择。预览保留原路径、重复项和解包大小防护，不关闭共享条目流。
- Compose DSL 文本输入按编辑顺序串行派发；本地已发出的文本回声不能覆盖当前光标、组合文本或
  失焦前的未确认编辑。明确外部新值仍可更新表单。页面重建/销毁取消未完成输入的等待动作，旧回调不得发布新页状态。
- 权限描述注册使用并发映射，继续复用现有工具权限和动作授权，不改变 FORBID/ASK/ALLOW 语义。
- 默认角色语音提示词仅在缺键时初始化；用户显式保存的空值保持为空。

## 工作流异步读取

列表与详情由原 WorkflowViewModel 分别持有读取代际，静默刷新接管此前显示的加载状态，
当前请求结束或取消时释放；旧请求不得结束新请求的加载状态。详情与执行记录的二次读取
使用同一代际，不能把上一个工作流的迟到结果发布到当前详情。

## 办公文档套件

`com.kiyori.office_suite` 由 ToolPkg 管理；TypeScript 层只处理参数、文件搬运与工具结果，
格式处理统一在 `kiyori_office`。结构化块中的图片也通过同一搬运入口，遵循实际输入与输出环境。

动态引擎命令 `office_convert` / `pdf_create` 的顶层 `engine` 返回实际执行引擎。
DOCX/PPTX 缺模板变量报 `E_TEMPLATE_VAR_MISSING`，PDF 未知字段报 `E_FORM_FIELD_NOT_FOUND`；
锚点定位继续使用 `E_ANCHOR_NOT_FOUND`。PDF 按钮以实际外观状态填写，歧义或不可填写状态显式拒绝。
表格仅在默认策略得到全空表格时尝试文本策略，并返回切换或仍为空的告警；不承诺文本聚类保持原表结构。
Tier2 安装计划包含 `weasyprint`，安装仍遵守用户确认契约。布局与填写参数见随包指引。
页面预览使用现有 ImagePool 与媒体链接解析，自动把页图附入多模态上下文；每次最多 8 页，
2048 长边图可结合归一化区域裁剪读取细节。图像注册失败不能以 OCR 文本代替成功。

Word/PPT 的创建与增量编辑共用原生对象实现。图表数据修改同时更新缓存与嵌入工作簿，
先分离共享可变部件；删除不再引用的对象时移除对应关系。默认另存，原地写入需要显式参数。
PPT 动画与转场保存在原生时间线中，普通内容编辑保留既有动效；显式设置动画会替换该页列表。
结构报告和文本高度估算不等同于真实字体布局，静态图片也不证明放映行为。

DOCX 合并支持图片、OMML 与独立复制的原生图表/工作簿，未知嵌入关系仍拒绝。
XLSX 通过 `xlsx_format.print_setup` 显式设置打印区、纸张、方向与适配页数；调用方负责覆盖图表，
最后保存后重算并预览。公式缺缓存保留 null 与明确提示，不写成计算结果或自动重算。
ReportLab 创建与水印共用字体注册：默认 CID `STSong-Light`，显式系统字体先解析文件，
未知或无法嵌入时给出输入/格式错误，不静默换字体。

参数与制作流程见随包 [PPT 指引](../../../examples/office_suite/skills/kiyori-pptx/SKILL.md)、
[Word 指引](../../../examples/office_suite/skills/kiyori-docx/SKILL.md)、
[通用指引](../../../examples/office_suite/skills/kiyori-office-core/SKILL.md)；

## Registry 与执行上下文

- ToolPkg `manifest.api_version` 缺键时为 `1.0.0`，显式声明必须为宿主支持的 `1.0.0` 或
  `1.0.1`；空值、非法格式和未知版本直接报错。API 能力版本与 Kiyori 产品版本、市场
  `minAppVer/maxAppVer` 分开管理。普通脚本不伪装成有 manifest 的 ToolPkg 上下文。
- 每次 JavaScript 调用从实际执行的容器或子包获取 API 版本，版本化 facade 按当前调用
  选择实现；不能把首个包的版本缓存为全局事实。入口和相对模块共用词法别名隔离。
- `requires` 在完整扫描快照中校验版本、缺失依赖、歧义子包和依赖循环。依赖先于消费者
  加载，用户顺序仅排列无依赖冲突的候选。依赖出错时消费者一并拒绝；启用时解析依赖，
  禁用被启用插件依赖的包时明确拒绝。拖动顺序先保存，再发布到原运行时。
- 消息菜单和聊天运行状态 Hook 通过既有插件 registry 注册，随启用容器和加载顺序刷新。
  消息菜单操作绑定原聊天/消息，Compose 对话框复用原 ToolPkg 引擎与代际检查；关闭或
  重建后旧输入、模块加载和动作回调不能更新新界面。
- `Tools.Chat.call` 使用现有功能模型服务租约固定配置和参数，结束时释放租约；返回文本、
  工具标记及协议元数据，不执行模型返回的工具。`recordTokenUsage` 控制本次功能调用统计，
  不创建可见聊天或第二个请求服务。发送接口的 `await_started` 等待聊天服务确认接收，
  不代表模型已完成回复。

## 计划模式提交

计划启动由原插件实例内的 `PlanSubmissionCoordinator` 统一管理。身份包含聊天、环境、
工作区和规范化正文；同一工作区的写入串行占用，目标在点击时冻结。先保存计划，再关闭
该聊天的计划模式，最后等待宿主确认消息启动。视图重建查询同一回执，成功后不可重复启动。
只读失败允许重试；开始写入或发送后抛错保持 `unknown`，不能假定未执行。插件运行时重建后，
磁盘已有相同计划也只证明文件存在，状态保持未知，不自动再次发消息。

- `PackageManager` 使用 `PackageScanPublicationGate` 与 `initLock`；异步扫描入队前登记 generation，扫描只返回局部缓存和快照，代际检查、缓存、asset snapshot、registry 与 runtime 更新在同一发布锁内完成。
- 主动清缓存推进 generation，晚到扫描不能覆盖较新请求或通知 listener；只有一个 PackageManager 与 ToolPkg registry。
- `ToolPkgManager.clear()` 清空容器/子包索引，在 `executionEngineLock` 内摘除全部 JsEngine 上下文，再逐个销毁；manager 保持可用，后续获取创建新实例。
- `SkillManager` 使用一把 `mutationLock` 串行扫描、删除、导入和读取，局部构造后一次性发布不可变快照；技能与错误必须来自同一快照。
- JavaScript 模块工厂把宿主别名置于外层词法域，每个 CommonJS 源码单独函数作用域；压缩局部名 `_`、`Tools`、`console` 不被前导代码覆盖。入口与相对 require 共用工厂，源码 strict-mode 仍适用。

## MCP

- 工具发现完成后按服务立即注册，不等待其他慢服务。发现之前捕获配置身份与代际，最终
  注册和配置编辑共用 `MCPLocalServer` 锁；禁用、删除、连接或凭据变化立即使旧回执失效。
  即使之后恢复相同配置，旧任务仍不能重新发布。显示名称和描述变化不使连接失效。
- 工具缓存绑定连接配置指纹；旧版无指纹或配置不符的缓存需重新发现。缓存、启停状态和
  清理共用配置锁，先原子写盘再发布内存，避免多个服务完成时互相覆盖状态。指纹与代际
  只服务于缓存和生命周期校验，不把认证头、环境变量或令牌写入日志。

- MCP 安装先将完整归档解压到独立 staging，再在文件修改互斥边界内发布；ZIP 写入前检查目录表，不允许越出解压根或重复条目。插件目录保留相对多段 ID 兼容性，但拒绝父级跳转、链接路径、内部 staging 前缀及全局配置文件名；删除不跟随链接。
- 文件发布成功后才记录安装元数据；文件与配置不构成共同事务，后续配置或清理失败显示部分完成并要求刷新核对。安装/卸载操作在 ViewModel 中防重，失败保留操作身份，可明确重试；ZIP 重试使用点击时 URI，不读取后来选择的文件。

- MCP 页面操作由实际 ViewModel 生命周期持有，配置列表观察使用该 scope；一次性仓库调用不留下永久观察协程。命令加载同时发布插件身份、加载状态与结果，旧请求不得覆盖新目标；默认部署重新分析当前目标，自定义命令来自该目标的编辑草稿。
- 部署中阻止重复启动和环境变量修改，环境变量仅保留当前部署的重试上下文；关闭后清空。进度保留最近 2000 行并明确省略数量；查看旧输出不强行跟随。部署目录操作检查退出码，依赖命令与目录成功条件在同次 Shell 中执行，取消路径仍释放本次终端会话。

- `MCPLocalServer` 的配置读改写与重载共用临界区，同目录临时文件完整写入后原子替换，磁盘成功后发布内存。无法读取配置时保留原文件，拒绝编辑覆盖，页面提供重载入口。服务器运行状态使用独立文件，不构成跨文件事务。
- MCP 编辑只合并用户修改的字段，保留并发启停和安装状态；同字段已变为第三种值时报冲突。JSON 编辑固定插件和原配置，保存等待结果，失败保留草稿。远程端点接受没有内嵌凭据及 fragment 的 HTTP(S) 地址，Header 名称须合法且大小写不敏感唯一。

- `MCPManager` 原子持有每服务配置 generation、连接 client 与最后失败；单服务串行连接，bridge I/O 不占注册锁。
- 更新、注销、shutdown 使待发布连接失效；shutdown 清连接和失败但保留已注册配置。一次获取最多尝试连接一次，取消和线程中断继续传播。
- `MCPBridgeClient.callTool` 每命令最多提交一次。超时、连接错误、无响应或异常不能证明服务没执行；后续明确调用可重新连接，首个响应不被替换。
- `disconnect()` 只清本地 connected 标记，不停止服务或关闭共享 bridge socket；ping 失败清连接标记。
- `MCPBridge` 为普通命令持有一条串行连接，spawn 使用短连接。资源先发布再 connect，失败释放；取消关闭该 socket，阻止晚到响应污染下一命令。
- 线协议保持 newline-delimited JSON 与既有 host/port/keepalive。日志不记录参数值和响应正文。
- `MCPToolParameter` 仅对文本输入应用 schema 转换；结构化 JSON 保留解析后的真实类型和 null 位置，不重新解释 quoted string。默认 ToolExecutor 流在 collect 时才 invoke，提前取消没有工具副作用。

## 工作区

- `core.workspace.WorkspaceConfig` / `WorkspaceConfigReader` 持有 `.operit/config.json` 与默认网页配置；UI 编辑，核心服务消费，不反向导入 UI。
- 工作区命令在同一次 Shell 执行中先进入被引用的绝对目录；目录不可用时不执行后续代码。共享命令弹窗按 commandId 接收结果与取消，显示真实退出码或未确认状态；输出保留最近 2000 条记录并明确显示省略数量。专属终端启动等待写入，启动期间同一按钮防重，切聊天后的迟到结果不切换新聊天面板。
- 绑定/解绑等待聊天仓储实际写入，SQL 比较打开时的原路径与环境，冲突或已删除聊天不报告成功。工作区页面只请求现有 ChatViewModel 协调预览；服务器更新串行并核对当前聊天和绑定，无工作区时停止旧预览。LocalWebServer 每次请求使用同一份路径/环境快照，磁盘文件边界包含 canonical 路径分隔符，拒绝同名前缀相邻目录；预览不隐式创建缺失工作区。
- Android/Windows 导出先写独立临时产物，完成后发布唯一文件名且不替换已有文件；取消前未发布内容清理，已发布文件保留。表单校验来自当前值，Android versionCode 为正 Int，进度和完成回调在主线程发布；聊天所属导出随聊天切换或组件释放取消。HTML 打包器固定所选目录和入口，读取失败中止导出，复制期间支持取消并在清理完成前防止新任务重入。
- `WorkspaceDownloadDispatcher` 接收 typed 网络或 inline 请求，Browser adapter 委托同一 BrowserDownloadManager，不增加格式或 transport 所有者。
- `WorkspaceRuleFileReader` 使用既有 `read_file_full` 按约定查找根 AGENT.md/AGENTS.md；系统提示词通过核心能力消费。
- `WorkspaceChangeTracker`、`DepthLimitedFileObserver`、`GitIgnoreFilter`、`WorkspaceAttachmentProcessor` 持有观察、过滤和附件格式化，UI 只保留展示与备份编排。

## 内置脚本与市场

- 生产脚本和 ToolPkg metadata 提供双语名称、动作导向描述、明确分类及默认启用字段；声明环境变量的包首次安装默认关闭。
- 当前未发布内置包版本基线为 `1.0.0`；Search 名称统一为“OpenAI 搜索”“Brave 搜索”，协议 ID 保持稳定。
- 学术工具分类为 `Academic`，包含 arXiv、Crossref、PubMed、Semantic Scholar、OpenAlex；名称和 UI 分类不改宿主类型或接口。
- 市场 identity 属于 `com.kiyori.capability.extensions.market`，API、发布描述与安装匹配共用归一化和独立 ID 验证，UI 不持有这些规则。
- GitHub Release 资产是已经发布的独立产物；后续市场登记失败报告 `RegistrationFailed`，不能删除 Release 或资产。
- 制品发布复用同版本 Release 时不修改其元数据，同名资产须逐字节一致才可复用；不同内容要求发布新版本，不能先删后传。登记失败保存原登记内容与资产地址，明确区分 HTTP 拒绝与提交结果未确认；只有已知拒绝或请求尚未发送的情形支持原发布账号手动重试登记，该入口不重新上传。连接中断、超时、冲突与服务器错误不开放重发，关闭说明仍保留当前发布页的提交状态。该状态由当前 ViewModel 持有，不是跨进程的远端回执。
- 市场业务写请求不自动跟随重定向，也不因连接失败重试；2xx 才进入业务结果解析，下载统计的无跟随 GET 独立接受重定向。制品页修改仓库地址立即清理旧 Release/资产选择并取消旧读取，迟到结果不能重新绑定到新地址。
- 市场 Skill 更新复用 `SkillManager` 的目录发布锁：完整下载与校验后重验已安装目录及来源，市场标记随新目录发布；准备失败保留旧安装，名称变化或多个匹配目录必须明确报错。市场页面不能在导入前删除 registry 所属目录。
- 普通脚本导入/市场更新由 `PackageManager` 在原扫描发布锁内校验声明身份、旧来源散列及目标文件名，完整准备后原子发布；失败恢复原文件与注册状态，不能先删除旧安装。既有 JS/TS/HJSON 格式统一进入外部扫描与来源定位；TS 执行仍须遵循脚本指南的预编译约定。多个来源声明同一包名时拒绝任意覆盖。
- 已激活脚本更新后仍使用原必填环境变量校验；缺配置时保留新安装和启用意图，撤去活动工具，明确提示配置后再激活。市场记录已安装事实后展示此结果。包标识兼容更名不自动复制包作用域凭据；跨扩展名的文件与内存发布不构成跨进程事务。
- MCP 市场配置资料在 `MCPLocalServer` 配置锁内批次合并，连接、启停和实际安装路径保持最新事实；配置文件和市场标记不构成共同事务。
- 市场安装标记在同目录完整写入并同步后原子替换；读取只看到完整新旧内容，准备或发布失败保留旧文件。标记仍是现有本地安装来源投影，不代替各扩展registry。
- 市场评论新增、编辑仅在服务器返回成功后关闭编辑器；失败保留正文与错误提示。删除固定评论目标确认，提交占位由操作生命周期释放，页面隐藏时不展示该页面的弹窗。
- Skill/MCP 发布由原发布 ViewModel 持有提交、错误和成功状态，按点击时表单快照同步占位，完成前禁止重复提交；页面重建不重发操作。元数据和版本编辑返回时确认未提交修改，新发布保留既有本地草稿。贡献者发布版本可修改描述和详情，名称与分类遵循条目编辑权限，仓库来源保持不变。确认内容可滚动，分类读取失败提供明确重载。
- 市场认证缓存按当前 GitHub 凭据指纹绑定；每次获取缓存前检查现有登录与过期事实，认证完成后重验凭据，账号变化使旧结果失败且不缓存。该行为不重发市场业务请求；已提交的远端操作不会因退出页面而撤销。通知页按账号清理本地投影并取消旧读取与待跳转。
- “扩展”的四页签和各自顶栏操作复用完整 PackageManagerSnapshot，安装成功发布 catalog revision；保留页面刷新，重建页面读取当前快照。

## 工具箱

- 入口来自现有导航注册目录，动态 ToolPkg 工具继续走同一路由；卡片点击直接导航，采用共享主题与 Material 点击反馈，内容可随字体增高。
- Shell 执行复用 `AndroidShellExecutor` 的身份与权限规则；页面 ViewModel 持有同一次执行、草稿和最近 100 条去重会话记录，按钮、IME 和历史重执行共用同步占位。命令完成仅清除仍等于本次提交内容的输入，失败保留草稿。
- Shell 历史与建议来自同一份会话记录，不自动持久化命令或输出；清除记录须确认，不撤销已执行命令。页面重建不重新执行，后台页面不弹出错误或清除确认。退出/取消不构成底层命令未执行的证明。
- SQL 查看器在原 ViewModel 同步占位，翻页沿用当前结果的查询、页大小和已读偏移；修改输入仅影响下一次运行。SELECT/CTE 使用外层分页保留原 LIMIT，PRAGMA/EXPLAIN 不添加分页。页大小为 1–1000，错误输入明确提示；分页失败保留已有结果。此处固定的是查询参数，不是数据库跨页事务快照。

## Windows 工具包

- `com.kiyori.windows_bundle` / `windows_control` 保持稳定标识；手机 Compose DSL 和工具执行共用连接地址规范化。
- 地址与令牌由现有 `EnvPreferences` 持有，`setEnvs` 在同一 SharedPreferences 编辑器中发布关联字段；不会清空其他包变量。
- PC Agent 的执行端口与本机管理端口隔离，仍共用一个配置、文件与进程会话所有者。FRP 只映射执行端口。
- 监听配置由进程内唯一生命周期所有者应用，管理端口和 PTY 不重启；失败明确恢复旧监听。无效启动配置只开放本机管理，不启用替代执行地址。
- 当前网络候选由同一模块提供，代理/TUN 与虚拟网卡不进入自动 LAN 推荐；复制配置前重新核对运行监听、配置和令牌。
- 手机只有收到专用认证探测的明确成功才显示已连接；HTTPS 使用协议默认端口，支持反向代理路径前缀。
- Windows 请求禁用重定向、共享 Cookie 和连接恢复重试。传输丢失报告未知提交状态，不自动重做文件或命令操作。
- 文件移动/复制拒绝覆盖；写入先完成临时文件再发布，Windows 已有文件使用保留 ACL 的系统替换。
- 具体接口、安装、局域网/FRP 配置、限制与升级见 [PC Agent 指南](../../../examples/windows_control/resources/pc_agent/kiyori-pc-agent/README.md)。

## OpenAI 搜索

- `openai_web_search:openai_search` 是独立托管搜索工具；配置唯一来自 package-scoped `PACKAGE + HOST_SERVICE` 的 `ToolPkgHostEnvironmentRepository`，不跟随当前对话模型。
- 宿主持有 Key、认证、请求、解析与结果卡；JavaScript 不读取 Key，也不能提交任意 package ID 或变量名。
- `OpenAIHostedWebSearchRequestLifecycle` 持有提交与原子终态；`AdmissionController` 持有进程 FIFO 并发/RPM，默认排队 60s、请求 300s、connect 上限 30s、write 上限 60s。
- 搜索只发一次非流式 Responses POST；不自动重试、重定向、切模型/端点/Key、轮询或续流。计费探测只由设置页的明确动作发起。
- schema revision 7 保留 `url_citations_and_action_sources / url_citations / action_sources / structured_feeds`。原生 URL annotation 是引用区间依据，不能从回答文本猜 URL。
- 完整 ToolResult 用于 UI，主模型投影省略未引用来源、动作、query/usage 的重复大载荷；XML-safe JSON 保持传输边界。
- 探测证据绑定精确 fingerprint，含 credential 不可逆摘要，最多 16 项；持久化成功后才回调，配置变化需要新的证据。有效 URL 引用探测与时间/天气 structured feed 分开。
- 详细字段、来源与验证见 [OpenAI Hosted Web Search](../architecture/openai_hosted_web_search.md)。

## Bilibili 工具包

- `com.kiyori.bilibili_toolkit` 内的 Media 子包为 `bilibili`，默认关闭，16 项工具共用宿主私密 `BILIBILI_COOKIE`；JavaScript 不接触 Cookie。
- GET-only bridge 验证 URL 和每次重定向；nav `-101` 只在明确未登录且 WBI 图像 key 有效时接受，其他认证失败保留。
- API 仅对 socket timeout 和 500/502/503/504 最多重试两次；下载以 GET Range 验证范围与字节数，同 URL/headers/route 最多三次尝试，403/412/429、证书错误与取消不重试。
- API 与 CDN 使用匹配的桌面 Web 请求身份，媒体不带 Cookie；诊断保留 endpoint/phase/attempt/category，不记录 query 签名或原异常中的敏感数据。
- capture 复用一个视频上下文，逐步报告，失败仍保留非空 message 与 data；既有输出需要 `overwrite=true`。媒体后处理只用现有 Files/FFmpeg，staging 完成后发布。
- protobuf 弹幕最多 50 段，XML 是显式另一来源；两者都不代表完整历史。`user.full=true` 保留 user 并提供上游 profile，不合成缺失字段；`media=false` 不创建或删除媒体目录。
- 用户步骤与设备验收见 [Bilibili 专项](../../TODO/bilibili_toolkit/index.md)。

## 应用内 AI 动作授权

下表描述 Kiyori 产品的权限系统，不构成开发 Agent 的授权。

| 风险级别 | 操作边界 |
| --- | --- |
| R0 只读 | 不改变状态，通过工具门禁后不需要操作确认 |
| R1 低影响 | 本地、有界、易撤销；可由持久工具授权允许 |
| R2 高影响 | 持久、多对象、敏感或准备外部影响；默认一次确认，可对固定目标与范围显式会话授权 |
| R3 关键 | 难以撤销、特权、财务、账户或不可收回的外部动作；逐次确认，不允许会话/持久绕过 |

`FORBID / ASK / ALLOW` 决定工具是否可调用；具体命令的 R0–R3 决定是否可产生副作用。`ALLOW` 不绕过 R2/R3；同一动作的 ASK 与操作确认合并为一次决定。

## 工作区文件编辑

- `WorkspaceEditorState` 持有打开文件、活动标签、未保存与保存中状态。保存绑定路径和正文快照，工具成功且当前正文仍一致时才清除未保存标记；保存后关闭必须等待该结果。
- 保存期间继续编辑保留新的未保存内容。关闭非活动标签保持活动文件；关闭确认绑定路径，不能被标签位置变化替换目标。
- 外部文件刷新按单文件快照发布，未保存、保存中、已关闭或已改变的文件不被覆盖；不能用旧列表覆盖新打开文件。
- 编辑器回调按绑定路径更新正文；代码格式化、撤销与重做只作用于当前文件的编辑器。文件面板优先消费自身 Back。
- 未保存文件仍在编辑器内时，解除绑定需要先处理这些修改，不能通过解绑静默丢弃内存内容。

- 文件浏览器只在读取成功后同时发布路径、环境与目录内容；失败可见，创建/删除成功后在同一操作中刷新。新建只接受当前目录的单个名字并检查已有目标，删除先确认固定路径。
- 管理模式沿用绑定工作区的文件环境，不能在同一组编辑标签中混入另一 provider 的同名路径。
- 工作区模板写入本次 staging，完整创建后才移到最终目录；已有目录拒绝被隐式覆盖，用户可重新绑定以复用文件。模板复制和配置写入失败必须传播。
- 回滚清单与对象必须可读；清单路径限定工作区相对路径，对象按 SHA-256 验证。全部写入成功后才删除目标清单之外的文件；失败保留错误与备份，不能继续截断聊天历史。文件系统与 SQL 不具备共同事务，不能据此宣称跨系统原子恢复。
- 回滚在历史锁内重新定位持久消息边界。备份清单只在历史 SQL 成功后清理；清理失败仍完成聊天投影刷新，并报告已回滚但清理失败，不能继续自动重发。
- 未保存内容或进行中的保存阻止工作区回滚。恢复期间编辑器暂停写入，恢复结束（包括失败）后关闭已保存的文件标签，重新打开文件时读取实际磁盘，避免用旧正文覆盖恢复结果。

## 工作区人工命令与导出

- 命令按钮固定工作区与执行身份。workingDir 相对工作区解析，绝对目录保持显式含义，目录用 Shell 参数引用；进入目录失败不会运行正文。当前字符串命令接口只支持 shell=true，shell=false 明确报错，不当作 Shell 代码提交。
- Android 本地工作区只向实际本地终端会话提交，SSH 配置变化不能将手机路径命令投向远端。工具按钮执行期间阻止重复点击，完成后的预览刷新使用触发时环境。
- 绑定资格来自目录读取成功；读取失败不会开放绑定按钮。
- Android/Windows 导出共用源目录检查，拒绝越界符号链接、目录循环及读取失败，保留内部别名和空目录；复制逐块检查取消。结果先写独立临时文件，完整后发布到唯一名字，不覆盖已有导出。导出结果弹窗使用主题语义色，长错误与产物路径可滚动和选择复制。

- 非本地文档/图片/媒体预览临时文件属于当前可见预览，使用独立文件名，切换路径、版本或环境后释放；本地原文件不删除。PDF每页失败显示明确终态，渲染最长边不超过2048px；文档转HTML临时输出在转换结束清理，同一HTML的重组不重载工作表。
- 代码编辑器沿用已有浅深语法主题并跟随宿主，语言切换只改变高亮分类；补全菜单使用窗口坐标一次定位，正文显示区不足时上移，不能再次加父布局偏移。

- 配置读取只有在确认缺少配置文件时采用已有网页默认值；损坏、不可读和失效符号链接不能启动默认预览。页面异步读取并提供失败重载/文件管理入口，保存根目录配置后刷新。配置错误停止预览服务，文件编辑入口保持可用。
- Linux配置沿现有文件provider读取，页面只借用该provider身份；终端命令提交前核对配置来源、当前文件provider与实际终端provider一致。工作区会话与结果按路径/环境隔离。对任意工具不猜测环境参数：Linux工作区路径工具在toolParameters中明确指定匹配的environment。

- 工作区动作菜单保留可拖动入口，位置根据实际按钮尺寸与当前窗口约束，拖动结束才保存；操作通过可滚动菜单呈现，撤销/重做消费编辑器实际状态。未启用本地预览服务器且没有预览地址时，页面提供文件管理入口。当前Android/Windows导出只接受Android本地目录，非本地文件环境不显示此动作。

## 扩展配置编辑

- 环境变量表单固定打开时的字段、原值与草稿；外部包目录刷新不覆盖输入。只向既有 `EnvPreferences` 与 `ToolPkgHostEnvironmentRepository` 提交实际变更键，不清空或重写无关配置。
- 每个仓储的写入口共用锁，原值校验与关联字段批次写盘在锁内完成；当前值已等于目标时允许同一操作重试，第三种值报冲突。保存等待结果，冲突或写盘失败保留表单和输入，不显示原始配置异常。
- 全局偏好与容器偏好各自提交，没有跨文件共同事务；部分失败可能已有字段生效，关闭不撤销它们。界面明确说明并允许重试，不能宣称全部失败回滚。
- 未保存退出或转到网络代理需确认；保存中暂停编辑与关闭。敏感变量使用隐藏输入且不明文展示默认值；选择项暴露选中语义，使用独立清除按钮移除显式值。

- 扩展详情与脚本弹窗按包/工具身份隔离。详情默认工具读取原始元数据，各状态按原始基底合并；失败重载不触发工具执行。删除与源文件清理先确认固定目标，等待结果并保留失败状态。子包工具列表属于可见弹窗，关闭后取消其旧读取。
- 脚本执行固定点击时的代码与参数，在 IO 运行并在 Main 发布结果；父页回传的最近结果不重置弹窗中已有的流式结果。运行中关闭先确认并取消该界面的任务；既有或已提交的外部操作不承诺撤销。

## Skill 详情与导入

- 详情读取属于当前选中技能；关闭或切换时取消旧读取，失败可重载。目录预览按排序显式栈遍历并检查取消，符号链接只显示入口，不跟随其目标。删除确认固定目录，IO 等待实际结果，失败保留确认。
- ZIP 和手动输入都由原 SkillManager 的 mutationLock 串行管理，先准备完整 staging，再在同一技能根内发布到未占用的单个目录。元数据名称不能是绝对路径、父目录或多段路径，不能冒用导入临时目录前缀；合法中文名称保持可用。
- 外部文件显示名不作为缓存路径，缓存文件使用独立随机名字；显示名只参与经过校验的技能名称推导。删除技能和导入临时树使用不跟随链接的遍历。
- 导入 UI 冻结本次输入并消费带 installedDir 的明确结果，未安装时保留表单与错误，不能根据本地化文本猜测成功。已发布目录而后续刷新/清理失败时明确说明已生成目录，不能伪装为可安全重复的未执行。原字符串返回入口保持兼容。

- Skill 来源在没有根入口且发现多个候选 SKILL.md 时保留歧义错误，要求选择具体仓库目录或单技能 ZIP，不以遍历顺序选择安装对象。导入正文滚动，执行期间标签与字段固定。

## 工具可用性测试

- ToolTesterViewModel 持有页面会话内的执行和结果，单项与批量在启动协程前互斥占位；用例身份与工具名分离，多个同名工具用例不会覆盖结果。批量按目录顺序串行发出。
- 批量确认列明真实联网、测试文件上传、设备和本地查询范围；系统与 UI 操作排除在批量之外，进入详情明确运行。页面隐藏、离开或点击停止只取消后续调度，当前工具保留真实返回；生命周期中断时标记结果待核实，不承诺撤销外部副作用。
- 每个页面会话使用独立测试目录，清理用例只指定该目录；压缩目标位于压缩源目录外。中断不自动执行破坏性清理，目录在确认与清理参数中可见。
- 网格只有一个滚动所有者；参数和结果预览明确提供全文入口与完整复制，长正文分块显示。结果状态表示工具自身返回，不代表业务效果或设备验收通过。
