# AI 对话更新

## 实施范围

- 待发送消息队列按会话 ID 归属到 `ChatViewModel`
- 超大聊天消息按固定首段和同一事务分段读取，保持数据库与归档格式不变
- 发送消息时使用已选角色卡，不误用全局角色卡
- 新建模型配置默认启用 Tool Call，保留用户已保存的显式关闭值
- DeepSeek 低思考深度映射为 `reasoning_effort=low`
- 超长纯文本粘贴按设置转换为 UTF-8 文本附件
- 每个记忆空间保存独立的记忆提取附加规则
- 内置额外信息注入包并发采集，并受一个可配置绝对截止时间约束

## 排除范围

- A2A 外部 HTTP 服务
- 终端会话恢复与上游 terminal gitlink
- 未建立前置运行时的远端 MCP 架构重写

## 实施结果

- 队列状态已由 `ChatViewModel` 按 `chatId` 持有，切换会话不再串线或丢失
- 消息与变体正文通过 `ChatContentDao` 在同一 Room 事务内按 65,536 字符分段重组
- 普通发送、队列发送和 Web Chat 发送均保留当前选中角色卡语义
- 新配置 Tool Call 默认值、DeepSeek low、超长粘贴附件和记忆空间自定义规则均已接线
- `message_insert` 已并行采集启用项，共享一个 1–120 秒可配置绝对截止时间，并输出不含
  消息正文或设备采集内容的诊断日志
