# 设置视觉系统与语义配色

## 页面结构

设置页面继续以文件下载器设置页为结构基线：

- `72dp` 折叠距离
- `32dp / 60dp / 26sp` 到 `56dp / 16dp / 20sp` 的标题过渡
- `16dp` 圆角分组卡片
- 双行设置项、紧凑当前值和右侧动作
- `0.6dp` 分隔线
- `26dp` 圆角底部选择面板
- 禁用项使用 `42%` 整体透明度

结构尺寸保持稳定，颜色由 `KiyoriSettingsTheme` 提供，不再在组件中散落浅色常量。

## 浅深色 token

浅色使用略带冷灰的页面背景和纯白卡片；深色使用近黑页面背景与分层深灰卡片。蓝色只承担主要
动作、选中和信息语义，不铺满大面积标题栏。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| pageBackground | `#F6F7F9` | `#101215` | 页面和折叠标题背景 |
| cardBackground | `#FFFFFF` | `#1B1F24` | 分组卡片与底部面板 |
| primaryText | `#20242A` | `#F2F5F8` | 标题与设置项名称 |
| secondaryText | `#6E747C` | `#AAB2BC` | 说明与当前值 |
| mutedIcon | `#9AA2AC` | `#7F8995` | 箭头和非重点图标 |
| divider | `#E9EDF2` | `#2A3037` | 卡片内分隔线 |
| accent | `#1E88E5` | `#90CAF9` | 开关、选中和主操作 |
| disabledTrack | `#D5DAE1` | `#444B54` | 关闭状态开关轨道 |

## 语义图标色阶

彩色图标采用“低饱和容器 + 清晰图标色”，同一功能在浅深模式下保持语义，不直接复用一组 raw
颜色。

- 蓝：应用导航、浏览器、模型、常规信息
- 绿：账号连接、文件与数据、成功或可用状态
- 紫：AI、角色、语音和生成式能力
- 橙：上下文、性能、注意事项和高级参数
- 红：隐私、权限、删除、阻止和高风险操作
- 青：同步、网络、外部连接和语音输入输出
- 粉：外观、个性化、头像和视觉内容

设置首页与拆分设置根使用全应用 `KiyoriSemanticTone`。入口规格保存语义 tone，不保存浅色 raw
颜色；组件根据当前固定浅深主题解析图标前景与容器色。设置页不再维护独立色调枚举。

## 覆盖页面

第一阶段必须覆盖：

- Settings Home
- 账号与连接
- AI 助手
- 语音服务
- 界面定制
- 数据备份与同步
- 网页浏览器、文件下载器和视频播放器设置
- 主题与外观
- 语言、全局显示和布局调整
- AI 助手直接连接的模型、提示词、上下文、权限、统计和外部对话页面的主题色域

复杂子页可以保留既有业务组件和表单结构，但必须统一页面背景、卡片、文本、强调色、错误色和
顶栏，不允许继续受旧用户全局颜色影响。
