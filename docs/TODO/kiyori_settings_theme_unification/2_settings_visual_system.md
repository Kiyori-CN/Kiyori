# 设置视觉系统与语义配色

## 页面结构

设置页面继续以文件下载器设置页为结构基线：

- `72dp` 折叠距离
- `32dp / 60dp / 26sp` 到 `56dp / 16dp / 20sp` 的标题过渡
- `16dp` 圆角分组卡片
- 双行设置项、紧凑当前值和右侧动作
- `0.6dp` 分隔线
- `26dp` 圆角底部选择面板
- 禁用项使用 `42%` 整体透明度

结构尺寸保持稳定，颜色由 `KiyoriSettingsTheme` 提供，不再在组件中散落浅色常量。

## 浅深色 token

浅色使用略带冷灰的页面背景和纯白卡片；深色使用近黑页面背景与分层深灰卡片。蓝色只承担主要
动作、选中和信息语义，不铺满大面积标题栏。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| pageBackground | `#F6F7F9` | `#101215` | 页面和折叠标题背景 |
| cardBackground | `#FFFFFF` | `#1B1F24` | 分组卡片与底部面板 |
| primaryText | `#20242A` | `#F2F5F8` | 标题与设置项名称 |
| secondaryText | `#6E747C` | `#AAB2BC` | 说明与当前值 |
| mutedIcon | `#9AA2AC` | `#7F8995` | 箭头和非重点图标 |
| divider | `#E9EDF2` | `#2A3037` | 卡片内分隔线 |
| accent | `#1E88E5` | `#90CAF9` | 开关、选中和主操作 |
| disabledTrack | `#D5DAE1` | `#444B54` | 关闭状态开关轨道 |

## 语义图标色阶

彩色图标采用“低饱和容器 + 清晰图标色”，同一功能在浅深模式下保持语义，不直接复用一组 raw
颜色。

- 蓝：应用导航、浏览器、模型、常规信息
- 绿：我的账号、文件与数据、成功或可用状态
- 紫：AI、角色、语音和生成式能力
- 橙：上下文、性能、注意事项和高级参数
- 红：隐私、权限、删除、阻止和高风险操作
- 青：同步、网络、外部连接和语音输入输出
- 粉：外观、个性化、头像和视觉内容

拆分设置根继续使用全应用 `KiyoriSemanticTone` 表达状态和业务类别，但 Settings Surface
通过 `resolveKiyoriSettingsIconColors` 将七类身份映射为低饱和、浅深主题独立的图标前景与
容器色。该映射只作用于设置行，不改变文件管理、工具箱等非设置界面。设置首页由于同一屏固定
展示 16 个入口，使用设计层 `KiyoriSettingsHomeIconPalette` 保存 16 个产品身份。原始颜色只
存在于设计层，不散落到页面组件，也不成为持久化主题或第二套状态语义。

首页颜色与功能映射固定为：

| 入口 | 色彩身份 |
| --- | --- |
| 我的账号 | 可靠连接绿 |
| AI助手 | 生成式紫 |
| 语音服务 | 声音与输入青 |
| 小程序 | 轻应用蓝绿 |
| 网页浏览器 | 浏览蓝 |
| 视频播放器 | 播放红 |
| 音乐播放器 | 音乐琥珀 |
| 文档阅读器 | 阅读棕 |
| 文件下载器 | 传输橙 |
| 文件管理器 | 本地文件橄榄绿 |
| 广告拦截器 | 防护玫红 |
| 日志记录器 | 诊断灰蓝 |
| 界面定制 | 个性化粉 |
| 数据备份 | 数据靛蓝 |
| 开发手册 | 代码梅紫 |
| 更多功能 | 扩展蓝绿 |

浅色和深色模式中，16 个图标前景色和 16 个容器色分别互不重复；每对至少满足 `3:1` 的图形
对比度合同。

## 覆盖页面

第一阶段必须覆盖：

- Settings Home
- 我的账号
- AI助手
- 语音服务
- 界面定制
- 数据备份
- 网页浏览器、文件下载器和视频播放器设置
- 主题与外观
- 语言、全局显示和布局调整
- AI 助手直接连接的模型、提示词、上下文、权限、统计和外部对话页面的主题色域

设置首页第 4 个顶栏按钮是主题状态的轻量投影：菜单固定按“跟随系统 / 浅色模式 / 深色模式”
从上到下排列，点击后调用既有 `UserPreferencesManager.saveThemeSettings`。按钮不保留独立
主题状态；菜单宽度固定为 `156dp`，让选中勾与文字保持紧凑距离；浅色有效时使用暖色太阳，
深色有效时使用冷色月亮。

复杂子页可以保留既有业务组件和表单结构，但必须统一页面背景、卡片、文本、强调色、错误色和
顶栏，不允许继续受旧用户全局颜色影响。
