# 发布与真机验收

## 当前不构成发布通过的证据

- 静态品牌搜索
- Python 单元检查
- Gradle `assembleDebug`
- APK manifest 解析

这些证据只能说明代码和构建链路达到开发基线。它们不能证明 Android 设备上的视觉、手势、Back 行为、通知、默认助手注册或终端外部入口正确。

## 真机验收队列

- 启动器图标、圆形/自适应图标和应用标签显示 Kiyori
- About、帮助、反馈、分享图片和通知显示 Kiyori，链接指向 Kiyori 仓库
- 默认助手、悬浮窗、无障碍和后台服务入口可正常启停
- 终端入口显示 Kiyori Terminal，环境配置、命令执行和返回行为正常
- 旧 Operit 备份可导入，既有 `operit://` 回调和插件/ToolPkg/MCP 标识不被破坏
- 包管理的插件标签显示 APK 预置插件，普通脚本包仍位于独立标签
- 市场的插件筛选可下载、安装、更新和移除 ToolPkg，安装后出现在插件标签
- ToolPkg 注册的抽屉页面、输入框菜单、消息处理与配置页面可正常加载，并遵守各自生命周期声明
- 新建的插件、MCP、Skill、工作区、模型、导出、备份、日志和临时文件写入 `Download/Kiyori`，不会自动读取或删除 `Download/Operit`
- 从软件首页快速滑到 AI 首页后立即点击输入框或工具按钮不会回吸；立即反向拖动仍可中断未结束的 fling
- Android 8.0+ 至少覆盖一台真实 ARM64 设备，并记录型号、系统版本、APK SHA-256 和结果

验收完成前，任务状态保持 `verification_pending`。不要以模拟器截图或构建成功替代用户报告的现场症状复测。

## 发布前额外门槛

- release 签名配置和密钥保管完成独立审阅
- 隐私、许可证、第三方服务和商店元数据完成审阅
- 版本号、变更日志、安装迁移说明和回滚方案已冻结
- 发布包经过独立安装、升级、卸载和数据恢复演练
