# 交互与状态设计

## 抽屉层级

抽屉沿用浏览器子页面的隐藏、部分展开和全屏展开三态。手机竖屏首次打开显示约 `64%`
可用高度；横屏和大窗口继续使用共享抽屉的自适应部分高度。顶部拖动柄负责展开和收起，
内容列表保留独立滚动，避免输入框或列表手势被整张抽屉抢占。

抽屉从上到下固定为：

1. 标题与总览
2. 搜索框
3. 横向分类条
4. 可滚动工具包分组
5. 固定取消与保存操作区

固定操作区不跟随长列表滚动，用户修改后不需要滑到末尾才能保存。

## 搜索与类型分类

搜索使用大小写不敏感的包含匹配，覆盖：

- 工具包显示名
- 工具包内部名称
- 环境变量名
- 当前语言下的变量说明

变量当前值可能包含凭据，因此不进入搜索索引、状态摘要、日志或文档。

分类条按工具包的 `ToolPackage.category` 动态生成，使用一个“全部”入口加当前已导入且声明了
环境变量的工具包类型。例如当前包集合包含绘图、搜索和聊天工具包时，分类条显示：

```text
全部		Chat		Draw		Search
```

“全部”是操作入口，固定在第一项；其余类型统一按英文显示名忽略大小写后从 A 到 Z 排列。
空白分类统一规范为 `Other`，已有非空分类保留工具包声明中的原始名称。每项显示该类型中的
工具包数量。选择类型后只显示该类型的工具包分组，搜索继续在当前类型内匹配包名、变量名和
变量说明。

脚本包页面、环境变量横向分类条和环境变量“全部”列表使用同一个排序契约：

1. 类型按英文名称从 A 到 Z 排列
2. 类型内部先按工具包显示名的首字母排列
3. 英文名称直接使用 A 到 Z 首字母，中文名称使用简体中文拼音首字母
4. 相同首字母内使用简体中文校对顺序比较完整显示名
5. 完整显示名仍相同时，依次比较原显示名和内部包名，确保刷新后顺序稳定
6. 数字和其他符号开头的名称排在 A 到 Z 字母组之后

## 工具包分组

分组标题优先显示 `ToolPackage.displayName`，为空时使用内部包名；两者不同时在副标题显示
内部包名。分组同时显示所属类型。摘要显示变量数量和已填写数量，缺少必填变量时使用明确的
错误状态提示。

工具包头从原来的三行可变布局收口为两行：

- 第一行显示 `13sp / 16sp` 的工具包显示名和紧凑类型标签
- 第二行显示 `10.5sp / 13sp` 的内部包名与变量状态摘要
- 左侧使用 `32dp` 类型徽标和 `18dp` 图标，不再用显示名首字母
- 包头水平内边距为 `11dp`，垂直内边距为 `7dp`，分组间距为 `6dp`

展开后的变量项使用 `7dp` 垂直内边距和 `4dp` 内容间距。说明最多显示两行；默认值与说明
保持紧凑层级。输入区为 `42dp` 高的单行表面，聚焦时使用当前工具包类型色描边，既降低列表
高度，也保留明确的输入焦点。

初次打开时：

- 展开所有存在未填写必填变量的工具包
- 必填变量已经全部填写的工具包默认收起
- 只有可选变量或没有变量缺失的工具包默认收起
- 每次重新打开抽屉都根据最新已保存值重新计算，不继承上一次打开时的手动展开状态

用户可以独立切换每个分组。搜索词非空时，匹配组临时自动展开；清空搜索后恢复搜索前的
用户折叠状态。

## 草稿和关闭语义

打开抽屉时从 `EnvPreferences` 读取本轮涉及的变量值，之后只修改内存草稿。同一个变量名
即使被多个工具包声明，也只有一个草稿值；任一分组中的输入变化会同步投影到其他声明位置。

以下动作不保存：

- 点击遮罩
- 向下拖动到隐藏态
- 系统 Back
- 点击关闭或取消

“保存”沿用现有合并语义：空白值从全局环境变量集合移除，非空值写入；未在本轮工具包声明
中的其他环境变量保持不变。
