# 实施与验证

## 实施顺序

1. 从浏览器现有三态抽屉中提取共享的拖动、遮罩、可见内容视口和系统安全区处理
2. 保留 `WebSessionBrowserBottomDrawer` 原接口，让浏览器通过共享基础件继续工作
3. 新增包管理环境变量抽屉和纯筛选策略
4. 把包显示名、变量声明和现有值投影成分组 UI，不创建新持久化 owner
5. 在 `PackageManagerScreen` 中替换旧弹窗状态和调用
6. 删除 `PackageEnvironmentVariablesDialog`
7. 同步字符串、README、`CONTEXT.md` 和产品壳架构文档

## 第二轮视觉与排序精修

1. 新增包管理专用分类视觉策略，登记 17 个现有类型的唯一图标和浅深主题颜色
2. 让脚本包页面与环境变量抽屉共用类型规范化、视觉身份和排序比较器
3. 删除脚本包页面原有四类人工优先顺序和其余类型共用图标、颜色的实现
4. 将环境变量包头改为 `32dp` 图标徽标与紧凑两行文字
5. 压缩横向分类项、分组间距、变量说明和单行输入区高度
6. 类型统一按 A 到 Z 排列，类型内按英文或中文拼音首字母稳定排序
7. 增加配色唯一性、图标映射、中文首字母、类型顺序和页面分组顺序测试
