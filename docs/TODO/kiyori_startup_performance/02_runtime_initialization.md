# 运行时初始化分层

## 首屏必需阶段

主线程在挂载 Compose 前只建立首屏会立即读取的全局契约：

- 崩溃恢复标记与本轮日志轮换
- 用户偏好与 Android 权限偏好实例
- 应用语言
- Activity 生命周期管理器
- AI 消息入口与内置插件注册
- Android Shell、Shower 和 Waifu 运行时引用

该阶段保持幂等，不启动磁盘预热、数据库预热或调度工作。

## 首帧后阶段

首帧提交后在后台线程执行完整初始化：

- WorkManager 与退出清理任务
- 持久后台服务职责检查
- 长期记忆调度器
- PDFBox 与编辑器语言支持
- 图片、媒体和 Skill 压缩包缓存池
- 数据库、分词器、工作流、备份计划和无障碍提供者预热
- AI 默认工具注册

`performInitialChecks` 在该阶段完成后执行，确保权限检查和插件加载只观察完整运行时。前台服务或悬浮服务直接启动时仍调用同步的完整初始化入口，不改变既有服务契约。

## 并发边界

首屏阶段和完整阶段共享同一初始化锁与独立完成标志。完整入口先确保首屏阶段完成，再执行后续工作；多个入口不会重复初始化。

首页首帧只组合当前可见页面。相邻页面、屏幕外 AI 宿主以及 MCP 配置和安装目录扫描会等待第二个帧信号，确保第一帧已经完成后再恢复预组合或后台扫描。
