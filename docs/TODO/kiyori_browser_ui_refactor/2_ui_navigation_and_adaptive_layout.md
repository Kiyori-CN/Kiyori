# 页面、按钮与自适应布局

## Browser Home 层级

```text
Browser Home/
	WebSessionBrowserTopBar
	WebSessionBrowserSearchScreen（搜索覆盖层）
	ExternalOpenPrompt 或 DownloadSummary
	Active WebView 或 No-Tabs Empty State
	Browser Bottom Bar
	Overlay Layer/
		Tab Overview
		Browser Bottom Drawer/
			Toolbox
			History
			Bookmarks
			Downloads
			Userscripts
		Page Dialog 或 External Open Confirmation
```

Kiyori 五项全局底栏不属于该树。Browser Home 自身仍由 App Shell 路由选中，离开后其他根页面恢复其原有全局底栏。

## 顶部区域

当前实现使用新的浏览器顶栏和全屏搜索覆盖层：

- 状态栏安全区由地址栏处理
- 点击搜索框进入全屏搜索，提交使用 `BrowserAddressResolver`
- 顶栏固定显示返回、搜索框和刷新或停止
- 搜索页持久化当前引擎与最近记录，提交和打开记录都调用共享 Browser Runtime
- 下载活动条和外部打开确认继续位于地址栏下方

## 浏览器底栏

| 位置 | 图标语义 | 可用条件 | 动作 |
| --- | --- | --- | --- |
| 1 | 后退 | `canGoBack` | 当前活动 WebView 后退 |
| 2 | 前进 | `canGoForward` | 当前活动 WebView 前进 |
| 3 | 主页 | 始终可点击 | 在活动标签打开 `about:blank`；无标签时由 runtime 创建标签 |
| 4 | 标签页计数 | 始终可点击 | 打开全屏标签总览 |
| 5 | 工具箱 | 始终可点击 | 打开 Partial 状态底部抽屉 |

底栏使用五等分点击区。图标保持 `24dp` 左右，最小点击目标不少于 `44dp`；无文字常驻标签，所有按钮提供中文 content description。禁用的后退和前进降低对比度但仍保持布局稳定。

标签计数使用描边方框表达窗口集合，显示总数 `0` 至 `99`，超过后显示 `99+`。无标签时点击计数仍可进入总览并新建标签。

## 工具箱主网格

主网格在 Compact 使用五列，顺序固定：

| 位置 | 标题 | 次级信息 | 动作 |
| --- | --- | --- | --- |
| 1 | 历史记录 | 无 | 抽屉内容切换到历史 |
| 2 | 收藏 | 无 | 抽屉内容切换到收藏 |
| 3 | 下载 | `n 个进行中 / m 个失败` | 抽屉内容切换到下载 |
| 4 | Userscripts | 详情页显示完整管理说明 | 抽屉内容切换到脚本管理并刷新 UI 状态 |
| 5 | 手机模式或电脑模式 | 标题表示将切换到的目标模式 | 收起抽屉后调用现有 UA 模式切换 |

工具箱标题区显示“工具箱”和当前浏览模式。每个格子使用主题 surface、onSurface 与 primary 系列颜色，不复制旧项目的纯黑图标和硬编码白底。

当前页面存在 userscript 菜单命令时，在主网格和底部动作区之间显示独立区段。命令按现有顺序排列，点击先收起抽屉再执行；没有命令时不保留空白区。

## 工具箱底部动作区

| 左 | 中 | 右 |
| --- | --- | --- |
| 关闭当前标签页 | 收起抽屉 | 关闭全部标签页 |

- 左右动作都显示图标和可识别标签，避免只靠图形猜测。
- 关闭当前标签使用普通 onSurface 色；关闭全部使用 error 色。
- 点击关闭动作先收起抽屉，再调用现有 runtime callback。
- 本轮不增加第二套确认状态；关闭行为与现有功能保持一致。

## 标签总览

标签总览覆盖浏览器主体，但不移除后方 AndroidView：

- 顶部显示“标签页”和总数
- 中部为卡片网格
- 卡片显示标签序号、标题、URL、活动状态和关闭按钮
- 活动卡片使用 primary 边框或容器色
- 点击卡片切换活动标签并关闭总览
- 点击卡片关闭按钮仅关闭对应标签，保持总览打开
- 无标签时显示空状态和新建提示
- 底部固定为返回、新建标签、关闭全部三项
- 新建标签调用现有 callback 并回到浏览器主体
- 关闭全部调用现有 callback 并回到浏览器无标签状态

当前 runtime 没有页面预览投影，因此卡片使用结构化标题和 URL 区域，不生成假截图，也不读取旧项目预览文件。

## 功能抽屉

- 历史：保留当前会话历史和最近访问，并保留清空入口
- 收藏：保留打开和移除收藏
- 下载：保留进行中、已完成和失败筛选，以及原有任务动作
- Userscripts：保留链接安装、本地导入、确认、启停、删除、更新和页面命令
- 所有内容在 Expanded 状态可获得完整可滚动高度
- 空状态使用当前 Operit 风格的图标、标题和说明，不复制旧项目空白区域

## 自适应规则

| 窗口 | 标签网格 | 抽屉宽度 | 工具网格 |
| --- | --- | --- | --- |
| `< 600dp` | 2 列 | 窗口宽度减安全边距 | 5 列 |
| `600dp - 839dp` | 3 列 | 最大 `600dp`，居中 | 5 列 |
| `>= 840dp` | 4 列 | 最大 `680dp`，居中 | 5 列 |

- Compact 横屏提高抽屉初始可见比例，使工具网格和底部动作区无需先拖动即可到达。
- 标签网格卡片宽度随列数变化，标题和 URL 使用单行省略。
- 地址栏和底栏填满 presentation 宽度；宽屏不引入 Navigation Rail，因为浏览器 chrome 本身需要稳定的上下结构。
- 抽屉顶部不进入状态栏；底部内容应用导航栏 inset。
- 输入法打开时，抽屉和地址编辑区域应用 IME inset，WebView 尺寸变化同步到 host projection。

## 无障碍与触控

- 图标按钮的可点击目标不小于 `44dp`
- 标签计数对读屏表达真实总数，不朗读截断后的 `99+`
- 抽屉手柄提供“展开或收起浏览器抽屉”语义
- 下载状态和模式切换不只靠颜色表达
- scrim 阻断后方 WebView 触控；抽屉关闭后触控恢复
- 抽屉拖动仅从手柄开始，列表垂直滚动和 WebView 页面滚动不会被抽屉手势夺取
