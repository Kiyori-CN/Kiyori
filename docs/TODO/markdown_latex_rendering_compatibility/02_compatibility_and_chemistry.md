# 2. 兼容预处理与化学表达式

## 预处理顺序

1. 扫描公式主体，识别控制空格、反斜杠物理换行和缺失竖线命令
2. 读取平衡的 `\ce{...}` 参数，交给化学词法转换器
3. 保留其他 LaTeX 命令、花括号、脚本和换行
4. 返回原始公式与实际交给 `JLatexMathDrawable` 的公式，供错误日志使用

扫描器必须按字符工作，不能使用全局删除反斜杠或针对示例字符串的 `replace` 链。

## 化学语法范围

本轮覆盖：

- 元素符号和下标：`H2O`、`N2`、`AgCl`
- 计量系数：`2H2`
- 相邻带电粒子：`Ag+`、`Cl-`
- 显式多值电荷：`Fe^{3+}`、`Ca^{2+}`
- 反应箭头：`->`、`<=>`，并保留常见双向/单向变体
- 沉淀/气体标记：独立的 `v`、`^`
- 分组和括号中的化学文本
- 核素前缀和混合 LaTeX：`^{14}_{6}C`、`\bar{\nu}_e`
- 电荷和电子的上标表达

转换结果使用 `\mathrm{}`、下标、上标以及当前符号表中的箭头/方向符号，不生成
`xrightarrow`、复杂数组或后端未确认支持的扩展命令。

当前不宣称完整实现 `mhchem` 的所有高级语法，例如复杂箭头标签、键类型、复杂状态
标注和宏定义。为避免把分子下标误判为电荷强度，多值电荷使用显式 `^{...}`；未声明的
歧义简写不属于当前合同。遇到无法可靠读取的平衡参数时，预处理器必须报告结构化错误，
由统一诊断路径记录 `\ce`、原文和位置。
