# 3. 布局与诊断

## 正常公式布局

- 公式节点使用容器可用宽度计算轻度自适应比例
- 公式最多缩小到原尺寸的 `0.8`
- 缩小到 `0.8` 后仍超宽的公式保持该可读尺寸，由现有横向滚动承载
- 横向滚动只作用于公式区域，保留聊天页面纵向滚动
- 共享缓存 Drawable 在每次 span 绘制前恢复当前尺寸，避免不同容器之间互相改写 bounds

## 失败源码布局

- 显示现有 `common_render_failed` 提示
- 源码使用等宽字体、可换行、完整内容，不使用单行省略号
- 失败区域使用容器宽度测量，避免无限宽 `TextView` 把右侧内容留在可视区域之外

## 日志合同

开发模式的失败日志必须包含：

- 公式原始内容
- 预处理后的内容
- `JLatexMath Android 0.2.0` 与核心 `TeXFormula.VERSION`
- 异常类型和消息
- 解析器报告的行列
- 从行列或异常消息定位出的命令
- 位置对应原始公式还是预处理公式

日志不能吞掉异常，也不能把成功的本地构建当作真机视觉验收。
