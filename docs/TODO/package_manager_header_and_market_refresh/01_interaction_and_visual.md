# 交互与视觉

## 固定页面层级

页面从上到下固定为四层：

1. 宿主顶栏：左侧保留返回或抽屉入口，中间显示“包管理”，右侧显示四个页面级动作
2. 搜索行：使用单行紧凑搜索框，提示文字随当前页变化
3. 页签行：插件、脚本包、技能、MCP
4. 内容区：当前页列表或空态，是唯一垂直滚动区域

搜索和页签不进入列表，因此长列表滚动时仍能直接切换页面或修改搜索。四个页签继续使用现有
紫、青、橙、蓝语义色，当前页只在指示线和文字层级上加强，不增加大面积高饱和背景。

## 顶栏动作

动作从左到右严格排列：

| 顺序 | 动作 | 图标语义 | 行为 |
| --- | --- | --- | --- |
| 1 | 环境变量 | Settings | 打开现有三态环境变量抽屉 |
| 2 | 市场 | Store | 按当前插件或脚本包类型进入对应市场 |
| 3 | 添加 | Add | 按当前页打开现有文件选择器 |
| 4 | 刷新 | Refresh | 强制重新读取包目录快照 |

四个图标统一使用宿主 App Bar 前景色，以保证浅深主题对比和窄屏秩序。刷新执行中原位显示
小型进度环并禁用重复点击，不改变其他三个动作的位置。Skill 与 MCP 页不显示这组动作，
避免与它们页面内已经存在的市场、导入和刷新入口重复。

## 搜索行

- 外边距：水平 `16dp`，上下 `8dp`
- 最小高度：`48dp`
- 圆角：`14dp`
- 背景：`surfaceContainerLow`
- 描边：`outlineVariant`
- 左侧固定 Search 图标
- 右侧在筛选计算时显示 `18dp` 进度环，否则在有内容时显示清除按钮
- 搜索内容按插件、脚本包、Skill 和 MCP 分别保留，切换页签不会互相覆盖

## 错误入口

存在包加载错误时，在页签下方显示一行紧凑提示：

- 左侧使用错误图标和错误数量
- 中间说明“部分脚本或插件加载失败”
- 右侧使用 ChevronRight 表示可进入
- 整行点击继续打开现有 `PackageLoadErrorsDialog`

提示条占用正常页面流，不覆盖任何包卡片或开关；错误清空后自动消失。
