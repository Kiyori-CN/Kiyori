# 1. 首页视觉与自适应布局

状态：[DONE]

## 旧实现

旧首页包含大尺寸软件图标、副标题、surface 色搜索卡、输入提示搜索图标、分离的 Search/AI 按钮，并在宽屏切换为左右双栏。

## 新实现

- 顶部操作区贴合安全区：左侧天气，右侧窗口总览。
- 主内容使用居中单列：标题行在上，搜索框在下；常规高度通过实测标题尺寸，把搜索框顶部描边精确放在可用首页高度的 `38.2%`，标题和搜索框相对旧中线基准整体下移。
- 可用高度低于 `440dp` 时使用 `96dp` 搜索框，并把顶部位置限制在标题完整可见所需的最小位置；常规搜索框高 `114dp`。
- 标题为文字 `Kiyori`，圆环标志固定为约 `18dp` 并位于标题右上方，不随宽屏放大。
- 搜索框宽度按可用空间约束，Compact、Medium 与 Expanded 上限分别为 `544dp`、`584dp` 和 `624dp`，最小水平留白分别为 `24dp`、`48dp` 和 `72dp`；内部背景直接使用页面背景色。
- 渐变只绘制约 `1dp` 的清晰描边，不绘制外侧扩散、模糊或阴影，也不改变控件测量尺寸。
- 底部 Search/AI 位于同一个 `120×32dp` 圆角边框内并严格等分，文字与选项图标尺寸保持不变；中央细线分隔两项，选中项使用固定明暗蓝色和轻量圆角底，按压水波裁切在圆角选区内。
- 附件、语音、相机使用图标按钮和内容描述，不显示操作说明文字。

## 验收

- 手机竖屏、手机横屏、平板竖屏和平板横屏均不出现双栏、文字截断或控件重叠。
- 所有固定格式按钮有稳定尺寸，渐变描边不参与布局。
