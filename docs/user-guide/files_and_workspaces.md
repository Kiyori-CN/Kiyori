# 文件、工作区与 AI 产物

本指南说明当前文件管理器与 AI 默认输出的使用方式。手机、Ubuntu、SAF 和网络目录具有
不同访问能力；实现与设备验收分别记录，未支持的操作明确失败。

## 浏览与选择

从底栏进入文件管理器，从首页的“存储位置”选择“内部存储”。左右两栏分别保留目录、历史和选择；轻触切换
活动栏。顶部提供搜索和浏览选项，下方显示路径、存储位置与统计。

- 点击打开项目；首次左滑或右滑选中并进入该栏选择模式。
- 选择模式下点击切换选中，取消最后一项后恢复点击打开；系统返回可清空两栏选择。
- 滑动只加入选择，再滑动另一项会加入两者之间的可见范围；完成区间后重新确定下一起点。
- 全选、反选和清空只作用于活动栏；隐藏或筛掉的项目退出选择，两栏互不影响。
- 长按已选项目处理整组选择，长按未选项目只处理该项目。菜单打开时保留选择。

## 存储入口与会话

首页“存储位置 → 全部”列出内部存储、Linux、工作区和回收站四个内置位置，点击后直接打开。
内部存储显示可刷新容量；Linux 与工作区可切换首页和侧栏显示，隐藏的入口仍可从“全部”打开。
“全部”页不提供新增其他位置。

存储侧抽屉按本地、网络、书签、工作区和工具分类；通过按钮打开，点击遮罩或返回关闭。
长按网络、书签或工作区可编辑、删除入口、排序或创建桌面快捷方式；其他本地入口可重命名、
删除、隐藏和排序，根目录与内部存储固定保留。编辑入口不重命名、移动或删除实际文件。

工具箱提供 AI 对话、浏览器和交换窗口入口。设置往返与应用内最小化保留会话；收起后可从
棕金色悬浮球恢复，长按显示关闭按钮。该入口可与浏览器悬浮球共存。

## 显示偏好与刷新

在 **设置 → 文件管理器** 配置左右列启动目录、初始排列、列表大小、文件名行数、时间精度、
目录统计、刷新间隔和侧栏显示，并管理隐藏清单、权限与本机历史。
启动目录与初始排列仅用于新会话，其他显示偏好即时生效；当前目录、排序与过滤分别由各栏保留。

- **隐藏项目**：工具箱可分别显示系统隐藏项与手动隐藏项，隐藏所选项目、编辑路径或取消隐藏。
  手动隐藏只改变 Kiyori 显示，不改名、不移动，也不是加密保护。
- **刷新与排序**：顶栏作用于当前栏，两栏分别支持下拉刷新；刷新显示进度图形。
- **目录大小**：可见本地文件夹在后台统计，滚动和刷新保留已知数值，前台定期复核；手动刷新可立即重查。
  不可访问、超时或不支持统计的位置显示“大小不可用”，可以刷新重试。
- **快速定位**：右侧上下箭头柄可拖动定位，滚动时显示，停止后自动隐藏。

## 搜索与定位

搜索默认限当前目录，可包含子目录。手机高级搜索支持大小、时间、UTF-8 内容、大小写、
名称通配符/正则及隐藏项。目录结果直接进入，文件结果定位到父目录；定位筛选可在搜索入口清除。

| 限制 | 当前行为 |
| --- | --- |
| 扫描规模 | 最多 100000 项、显示 2000 个结果 |
| 内容读取 | 最多 4 MiB UTF-8；超限、非文本与不可读项目明确统计 |
| Linux / SAF | 名称搜索；高级大小、时间、内容与正则尚未支持 |
| 关闭搜索 | 取消扫描，拒绝晚到结果覆盖列表 |

## 搜索与任务历史

最近搜索保存最多 20 次记录，每次最多 1000 项结果；最近任务保存最多 100 条摘要。
两者重启后可回看，并可从设置清理。保存的搜索结果数量与一次实时扫描的显示上限不同。
任务历史只保存摘要，不自动重做文件操作，也不代表已支持中断任务恢复。

## 创建、传输与删除

新建先选择文件或文件夹，同名不覆盖，失败保留输入；结果未确认时先核对目录。
复制或移动可选另一栏，也可浏览目标后点击底部待粘贴条的“粘贴到此处”，核对完整来源与目标再执行。
同名项目可跳过或改名，不合并或覆盖。停止传输会等待当前项目完成；结果未确认时停止后续项目。
完成后可查看目标目录。取消待粘贴项目仅清空本次选择，不会删除源文件。

严格写入当前支持应用可访问的手机目录。移动限同一文件系统，跨文件系统失败保留源项目。
Linux/SAF 严格写入、跨文件系统移动和任务持久恢复仍待完善。

删除先统计清单再确认，默认移至同卷回收站；结果中可直接打开回收站，也可从左侧存储抽屉进入。
支持恢复原位置或再次确认永久删除；同名或原父目录丢失时保留回收内容并说明原因。
共享存储回收内容不会随卸载自动清除，需要在回收站手动永久删除；应用内部及旧专属目录的
回收内容会随清除应用数据丢失。失败时可复制操作详情；需检查的记录不会自动重试或删除。
属性提供大小、数量、时间和读写能力，
工具可复制名称、路径和计算文件 SHA-256。

Shizuku 授权后，刷新目录会按当前权限读取，不需要重新建立文件管理会话。`Android/data` 是共享存储
中的受限目录，系统 `/data` 则包含应用私有数据；Shizuku 的 Shell 身份不等同于 Root，系统仍可能拒绝。
访问失败会显示简短错误，可重新读取或打开“查看详情”复制完整诊断，不能据此认定目录为空。
能列出文件不代表严格复制、删除或内置预览已经支持特权访问。

## 打开、编辑与归档

| 内容 | 操作与边界 |
| --- | --- |
| 音视频 / 图片 | 内置播放器 / 可缩放预览，格式与设备支持分别判断 |
| 文本 | 不超过 1 MiB 的 UTF-8；原目录另存不覆盖副本，未保存退出会提示 |
| 本地 HTML | 长按文件，在“打开方式”选择“内置浏览器”；默认点击仍查看源码。也可在浏览器地址栏粘贴绝对路径或 file/content URI |
| PDF / Office / 其他 | 交给系统已注册应用；办公处理见 [扩展指南](extensions.md#办公文档套件) |
| ZIP | 压缩到同目录新文件，保留 Unicode 与空目录；未加密 ZIP 解压到新目录，同名不覆盖 |
| 分享 | 文件使用系统分享；目录先确认生成 ZIP，归档留在原目录 |
| 网络目录 | FTP、FTPS、SFTP、WebDAV、S3 兼容连接与浏览；远程打开和写入尚未接入 |

本地网页需要应用具有读取权限。手机普通目录中的 HTML 保留同目录图片、样式的相对地址；
系统文件提供方的 `content://` 地址受该提供方和临时授权限制，不保证可加载相邻文件。
Linux、网络目录中的网页请先复制到手机存储。查看响应式网页的桌面布局时，可在浏览器 UA
选择 PC 桌面；它同时启用宽视口布局，网页仍可能按账号或自身规则提供不同内容。

文件书签定位到父目录并筛选文件名。Linux/SAF 内容打开和原文件编辑保存以页面实际支持为准。

## 对话工作区与默认输出

### 让 AI 查看路径中的图片、音频和视频

在聊天模型配置中开启该模型实际支持的“直接处理图片/音频/视频”能力，并选择支持该输入的
API 协议后，可以直接提供文件绝对路径，例如“查看 `/sdcard/Download/Kiyori/chart.png`，
分析颜色、图形和布局”。Agent 的文件读取工具会提供对应原生媒体参数，不需要先手动添加附件。

手机路径、Ubuntu/SSH 路径和附加储存仓库属于不同环境，描述时说明文件所在位置。Linux/SSH、
SAF 和只能通过高权限身份读取的媒体传输上限为 20 MiB；大音视频可先明确要求截取所需片段。
视频容器、编码、时长及模型支持情况仍由设备和服务商决定。

PDF、Word、幻灯片需要看版式时，请要求文档工具渲染页图后查看；文本提取和 OCR 不能证明 AI
看到了页面布局。读取或模型请求失败会明确显示，不会把元数据冒充成媒体理解。历史媒体缓存失效时，
可在新对话重新读取，或先从当前历史移除失效媒体引用后重新附加；仅重复发送不会恢复原链接。

具体协议支持范围见 [AI 输入契约](../doc-src/contracts/ai_execution.md#绝对路径与多模态输入)。

### 工作区与输出目录

目录工作区列表与 AI 对话绑定是两个操作。浏览或添加目录不自动改绑对话；绑定后，工具
读取本次调用所属对话的工作区，项目规则沿用 `AGENT.md` / `AGENTS.md` 和 `.operit/config.json`。

在 **设置 → AI 助手 → AI 产物保存位置** 设置默认目录：

| 环境 | 初始根目录 | 常见分类 |
| --- | --- | --- |
| Android | 内部共享存储的 `Download/Kiyori/workspace` | `office/<task_id>`、`bilibili/library`、`browser` |
| 本地 Ubuntu | `/workspace` | `code-runner`，以及显式选择 Linux 交付的办公任务 |

明确指定的目标优先；未指定时，匹配环境的对话工作区优先于默认设置。Android 与 Ubuntu
是独立文件系统，跨环境需要显式复制；SSH/MCP 不共享手机本机目录。更改默认值不搬移旧文件、
不修改已有会话 cwd，也不改变运行环境、依赖与缓存位置。手动下载、备份和审计导出使用各自目录。

Android“选择文件夹”只接受内部共享存储目录，云盘与 SD 卡 URI 暂不支持，也不额外授予
Shell 权限。“恢复默认”只修改草稿，保存后生效；“检查写入”会创建目录并读写、清理临时文件，
只证明当前应用的直接访问能力。目录错误应修复设置或显式指定匹配环境路径。
