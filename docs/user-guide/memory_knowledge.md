# 管理记忆与知识

从 AI 对话左侧抽屉进入记忆库。标题右侧从左到右为“关系图谱、筛选、设置、刷新”，长按图标可查看操作说明。
页面上方左侧显示当前空间与文件夹，右侧切换“记忆”或“知识”，下一行是搜索框。
点击位置打开“空间与文件夹”面板；空间旁的更多菜单提供新建、重命名和删除空间。
空间沿用助手角色的绑定规则；在这里切换全局活动空间，不会改写固定绑定的角色。

## 保存什么

- **记忆**：偏好、稳定事实、已经确认的决策、可复用经验或带有时间背景的事件。
  例如“项目 A 的接口测试需要先启动本地数据库”，比整段失败日志更适合保存。
- **知识**：文档、参考资料和笔记。导入文档后保留来源 URI，正文分块保存，可以查询并读取相应块。
- **用户档案**：仍使用已有的 `user.md` 页面维护。资料正文或自动生成的记忆不能替代操作授权。

新建时填写标题和正文，选择主题、文件夹与标签，并记录来源。文件夹表达项目或领域，标签用于交叉检索。
既有条目保留原标签和目录；旧文档自动显示在知识页，不复制一份数据库。

## 查找与整理

搜索标题、正文或标签后提交查询；搜索保留当前空间、文件夹、内容类型和归档范围。
输入后点击搜索图标或键盘搜索键提交；尚未提交的新关键词不会冒充已有结果的查询条件。
“筛选”面板集中选择主题、标签、排序与“只看已归档”，选择即时生效，点击“完成”返回内容。
标签较多时可以在面板中查找标签；首页只展示生效的筛选，点选中的条件可移除它。
筛选面板内的“重置筛选”清除主题、标签、归档和排序，保留当前空间、文件夹、记忆/知识页与搜索词。
空结果页的“重置筛选”仍可清除搜索和文件夹范围，返回当前类型的全部内容。
位置和筛选采用与浏览器下载、历史一致的底部抽屉：上拖展开，下拖收起，关闭或点击遮罩退出。
列表优先展示标题与摘要，并显示精简的来源、更新日期、主题、文件夹和标签。空库直接提供新建/导入；
已有内容时右下角提供添加入口，知识的添加菜单同时提供导入资料和新建笔记。
新建默认使用当前文件夹；编辑中有未保存修改时，离开前会确认。可信度、重要性收在“高级属性”。
点条目进入阅读详情，“条目信息”可展开来源、UUID、时间和索引状态；编辑是主操作，
归档/恢复与删除在详情的更多菜单中。归档从日常及 Agent 查询中排除条目，但保留内容。
在筛选中开启“只看已归档”后可恢复；归档与删除不是同一操作。

文件夹行的更多按钮提供重命名与删除。重命名父目录时，当前子目录位置同步更新。
删除文件夹会将该目录及子目录的内容移至未分类，保留记忆、文档正文与关系。

顶栏“关系图谱”用于检查关联，选中时再次点击返回列表。为控制布局成本，只显示当前结果的前 200 项，
完整结果仍在列表中。关联和框选操作只在图谱模式出现。
更改查询、目录或筛选后需重新框选或选择关联节点，避免旧范围中的隐藏条目继续成为操作目标。

## 导入与文档编辑

知识页提供“导入资料”和“新建笔记”。支持文本及已有文档提取工具可处理的 PDF、Word 类型。
二进制资料上限为 32 MB，提取文本上限为 200 万字符；超限时需要拆分，不会静默截断后称为完整导入。
区块最多 1800 字符并保留有限重叠，使长段落有明确输入上限。原始文件不会因删除库内文档被删除。

导入期间显示读取与保存进度，当前空间与新建入口暂停操作，避免重复导入。
文档详情可搜索已保存正文或逐块编辑。“保存全部”作为一次保存处理；失败时保留编辑内容，
关闭前确认未保存修改。保存期间输入锁定；归档需先保存或放弃当前文档修改。
如条目在编辑期间已被其他操作修改，刷新并核对后再保存，避免覆盖新内容。

旧版本数据无需清空。历史文档仍归入知识，未填写主题的旧条目按“其他”显示；
旧向量没有模型来源时标记为待重建。云端嵌入关闭时显示本地保存与关键词检索状态。
索引统计在设置中按需加载，失败时显示原因并可刷新；列表首屏不主动扫描全部向量。

## 自动整理与语义检索

设置中的自动整理开关复用应用原有的记忆自动更新设置。关闭后停止后续自动候选处理，
手动指定保存和读取既有记忆仍可用；已经执行中的操作不会被回滚。
自动整理失败保持在候选队列；自动合并的原记录进入归档，便于审阅和恢复。

未启用云端嵌入时，仍可本地管理与关键词检索。启用后，索引文本和语义查询会发送到配置的服务，
使用现有网络路由。凭据脱敏复用应用既有规则，但保存前仍应检查正文是否包含不适合长期保存的信息。

“语义索引待构建”表示文本仍可用，但缺少与当前模型和内容匹配的向量。
旧向量没有可验证模型来源、更换端点/模型、内容修改都会影响有效性；在设置中重建并查看结果。
相同维度不能证明两个模型兼容。请求或索引损坏会显示错误，不能把服务失败解释成“没有记忆”。

## Agent 如何读取

Agent 先查询候选摘要，结果带 UUID、来源、类型和更新时间；需要完整内容再按 UUID 读取，
文档可按分块读取。查询每次最多 100 项，复用查询快照可以继续获取未返回的结果。
同名标题需要用 UUID 准确定位。记忆可能过期，重要且易变的信息仍应重新核实。

新版本 JSON 备份包含文档正文块、标签、关系、类型和归档，接受旧版本记忆备份；
向量与 API Key 不随该 JSON 备份导出，恢复后按需要重新构建索引。
